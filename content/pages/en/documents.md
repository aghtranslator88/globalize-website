# Official Document Translation Guides

> **Answer Box:** Use this directory to reach the guide that matches your document: a birth certificate, movement certificate, or police record. Each guide explains what to prepare before requesting translation. If your document is not listed, send a legible copy with its name, issuing country, and intended recipient so the correct scope can be assessed.

Official records differ in structure, data, and purpose. They should not be treated as interchangeable forms. This directory helps you select the relevant document page before sending a file and reduces confusion between similarly named records or between translation and a separate procedure requested by a recipient.

## How do you choose the right guide?

Begin with the official title printed on the document, not only the informal name used in conversation. Countries and authorities may use similar labels for records that are not equivalent. Next, identify the issuing country, intended recipient, and purpose. Those details help route the enquiry correctly and reveal whether specialist handling or a separately requested procedure may be relevant.

If the submission contains several documents, separate them by type and language. One case might include a birth certificate, a police record, and another official record, but each file still needs its own completeness and data checks. Instructions for one item should not automatically be applied to the others.

For the broader meaning of certified translation and the role of a stamp, authorized signature, or accuracy statement, visit [Certified Translation Services](https://www.globalizetl.com/en/certified). That page owns the service-level explanation; this directory only routes users by document type.

## What should you send for an initial assessment?

Prepare enough information for the request to be understood without assumptions:

- a complete, legible copy of every page, including stamps, annotations, and any relevant reverse side;
- the document’s official name and issuing country or authority;
- the current language and requested target language;
- the recipient, destination country, and submission purpose;
- any written instructions supplied by the recipient;
- required name spellings that must match a passport or another identity record;
- the requested deadline, so feasibility can be assessed rather than inferred from a general promise.

An enquiry can begin with a clear electronic copy. Whether an original, a particular format, or another step is needed can be determined only after the document and recipient instructions are reviewed. Being listed in this directory is not an acceptance or outcome guarantee; the receiving organization makes its own decision.

## What if your document is not listed?

Send Globalize a readable copy together with the basic information above. The file can then be classified as an official-document request or routed to a specialist service such as legal, medical, business, or technical translation. Do not choose the closest-sounding page when the underlying record is different; correct routing depends on the document’s content and intended use.

This directory does not publish a universal price or turnaround. Assessment may depend on language pair, volume, source quality, specialization, formatting, requested deadline, and any separately confirmed steps. A quotation is prepared after the actual request has been reviewed.

## Common mistakes before sending a document

- sending one page from a multi-page record;
- cropping an edge, stamp, annotation, reference, or number;
- using an informal label instead of the document’s official title;
- omitting the issuing country or intended recipient;
- assuming a translation stamp automatically replaces notarization or legalization;
- relying on outdated requirements or a different applicant’s process;
- requesting a final price or deadline without a reviewable copy.

## Frequently asked questions

### Which documents are currently listed in this directory?

The directory contains dedicated guides for birth certificates, movement certificates, and police records. Each guide covers its named document, while the certified translation page explains the broader service.

### What should I do if my document is not listed?

Send a legible copy with the official document name, issuing country, languages, recipient, and purpose. Globalize can assess the file and identify the suitable service route. The absence of a dedicated page does not mean the document cannot be assessed.

### Does being listed guarantee that my document will be accepted?

No. The directory helps you choose a translation route and prepare an enquiry; it cannot guarantee a decision by an embassy, university, court, government office, or any other recipient. Check the recipient’s current instructions and send them with the document.

### What information is needed to start a request?

Send a complete legible copy, the document name and issuing country, source and target languages, recipient, purpose, requested deadline, and any written instructions or name spellings that must be matched.
